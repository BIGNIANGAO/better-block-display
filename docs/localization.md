# 语言支持

1.0.6 支持游戏本体的 24 种正常语言。语言枚举依据本机游戏 12-18-2022、Steam build 10180494 的 `Settings.GameLanguage` 核对。内部枚举 `WWW` 不作为正常语言支持，使用英文回退。

设置页名称、三个开关、辅助说明、悬停提示、来源计数和部分预估原因各有对应语言的文案，每种语言共 24 项。旧版“显示总量”开关的文案仍保留在资源中以维持条目顺序，当前界面不再显示该开关，护盾数字始终显示预计总格挡。游戏设置语言后重启，模组在初始化时加载相应文案。未知或缺少资源的语言回退为英文；资源路径用 `Locale.ROOT` 生成，避免土耳其语系统区域设置改变字母大小写后导致找不到文件。

卡牌、遗物、能力和球的来源名称直接使用游戏或对应模组提供的名称。「无惧疼痛」「虚无」和格挡用语参考本体相应语言的译名。第三方模组没有提供翻译的来源名称会保留原名；本模组不会代替第三方翻译。

ModTheSpire.json 的模组名称「更好的格挡显示」和简介「将格挡量由实时改为回合结束后的值」是固定中文，启动器中的元信息不随游戏语言切换。游戏内的模组名称、简介、设置页面及战斗内提示会随语言切换；英文名为 Better Block Display。

新增翻译尚未经过各语言母语使用者审校。结构、占位符和字体检查不代表所有表达已达到母语质量。修改单个语言时须保留 `TEXT` 数组的顺序和 `%d`、`%s` 占位符。

构建后的 `audit.ps1` 检查全部语言是否打包、条目是否完整、占位符是否与英文一致。`smoke.ps1 -Language JPN` 等命令在隔离的真实游戏环境中检查语言选择、英文回退、字体覆盖和设置文本宽度，测试不写入正常存档。当前版本的运行检查记录见 [验证记录](verification.md)。
